## 1. 两个终端与构建

两个终端都进入 WSL Ubuntu，并在各自的 `lab2/code` 目录工作。下面不包含个人机器绝对路径。

终端一：

```bash
mkdir -p ../debug-report
make clean
make DEFS="-O0 -fno-inline"
qemu-system-riscv64 \
  -machine virt -m 128M -nographic \
  -bios default -kernel bin/ucore.img \
  -gdb tcp:127.0.0.1:1234 -S \
  2>&1 | tee ../debug-report/01-bestfit-serial.txt
```

终端二：

```bash
gdb-multiarch -q bin/kernel
```

在 GDB 中逐条输入；每条完整命令后按一次回车。不要粘贴 Markdown 反引号，不要把一个表达式拆成两次输入：

```gdb
set pagination off
set confirm off
set print pretty on
set architecture riscv:rv64
set logging file ../debug-report/01-bestfit-gdb.txt
set logging overwrite on
set logging enabled on
target remote 127.0.0.1:1234
```

本次使用过旧别名 `set logging on/off`，GDB 给出了弃用提示；这里使用新拼法。首次记录前确保日志目录存在。

## 2. 物理入口、高地址入口与 kern_init

```gdb
thbreak *0x80200000

p/x $satp
thbreak paging_enabled
continue

p/x $satp
x/10i $pc
p/x (unsigned long)&boot_page_table_sv39
set $root_pa = ((unsigned long)$satp & 0xfffffffffff) << 12
p/x $root_pa
x/gx (unsigned long)&boot_page_table_sv39 + 511*8
```

对应报告图 G1—G3。断点在 `kern_init` 序言之后，栈帧导致 `sp` 低于栈顶；不能要求二者相等。

## 3. 当前根级叶子的地址核算

```gdb
set $va = (unsigned long)&kern_init
set $vpn2 = ($va >> 30) & 0x1ff
set $root_pte = *(unsigned long *)((unsigned long)&boot_page_table_sv39 + $vpn2*8)
p/x $va
p/d $vpn2
p/x $root_pte
p/x $root_pte & 0xff
set $pa = (($root_pte >> 10) << 12) | ($va & 0x3fffffff)
p/x $pa
p/x $va - 0xffffffff40000000
p $pa == ($va - 0xffffffff40000000)
```

对应图 G4，只适用于本项目当前根级 1 GiB 叶子，不是所有页表的通用转换公式，也不是宿主 MMU/TLB 单步记录。

## 4. page_init 与初始化结果

```gdb
tbreak pmm_init

tbreak page_init

list

p/x va_pa_offset
set $desc_pa = (unsigned long)pages - va_pa_offset

set $first_free = ($free_pa >> 12) - nbase
p/x $desc_pa
p/d $desc_bytes
p/x $free_pa
p/d ((npage << 12) - $free_pa) / 4096
p 'best_fit_pmm.c'::free_area.nr_free

p (pages[0].flags & 1) != 0
```

对应图 G5—G6。前两次 `next` 针对本快照第 73/74 行；应根据当前停住的语句判断变量是否已赋值。`finish` 后不再读取该函数的局部变量。

## 5. Best-Fit 链表与真实自检

先定义只读链表显示命令，注意两个 `end` 分别结束 `while` 与 `define`：

```gdb
define show_best
set $bf_head = &'best_fit_pmm.c'::free_area.free_list
set $bf_node = $bf_head->next
set $bf_offset = (unsigned long)&((struct Page *)0)->page_link
set $bf_seen = 0
p 'best_fit_pmm.c'::free_area.nr_free
while $bf_node != $bf_head && $bf_seen < 20
set $bf_page = (struct Page *)((unsigned long)$bf_node - $bf_offset)
printf "head=%p pages=%u flags=%lu\n", $bf_page, $bf_page->property, $bf_page->flags
set $bf_node = $bf_node->next
set $bf_seen = $bf_seen + 1
end
end
```

5 页分配，对应图 G7：

```gdb
tbreak best_fit_alloc_pages if n == 5
continue
bt
p n
show_best
set $bf_before = 'best_fit_pmm.c'::free_area.nr_free
finish
set $bf_allocated = (struct Page *)$a0
p $bf_allocated
p *$bf_allocated
p $bf_before - 'best_fit_pmm.c'::free_area.nr_free
show_best
```

选择 1 页精确匹配块，对应图 G8。此条件依赖前述自检顺序：

```gdb
tbreak best_fit_alloc_pages if n == 1 && 'best_fit_pmm.c'::free_area.nr_free == 3
continue
p n
show_best
finish
set $bf_chosen = (struct Page *)$a0
p $bf_chosen
show_best
```

归还 5 页并合并，对应图 G9：

```gdb
tbreak best_fit_free_pages if n == 5 && 'best_fit_pmm.c'::free_area.nr_free > 0
continue
p base
p n
set $bf_release = base
set $bf_free_before = 'best_fit_pmm.c'::free_area.nr_free
show_best
tbreak best_fit_insert_free_block
continue
p base
p *base
list
finish
show_best
p 'best_fit_pmm.c'::free_area.nr_free - $bf_free_before
```

观察终端一自检成功（图 G10）后，在终端二 Ctrl+C，再输入：

```gdb

```

在终端一 Ctrl+A 后按 X 退出 QEMU。这里的 `SIGINT` 是用户暂停，并非异常失败。

## 7. 受控 16 页区的复现步骤与截图边界

图 G13 只保留合并后的结果。下面整理受控测试的定位方法，供补拍拆分中间过程；**不将未截图的命令执行过程冒充已有完整记录**。

```gdb
tbreak buddy_split_check
continue
set $arena_head = arena
tbreak buddy_alloc_pages if n == 4
continue
p buddy_nr_free
p buddy_free_area[4].nr_free
p buddy_free_area[3].nr_free
p buddy_free_area[2].nr_free
finish
set $split_allocated = (struct Page *)$a0
p $split_allocated == $arena_head
p $split_allocated->property
p buddy_nr_free
p buddy_free_area[4].nr_free
p buddy_free_area[3].nr_free
p buddy_free_area[2].nr_free
p ($arena_head + 8)->property
p ($arena_head + 4)->property
tbreak buddy_free_pages if base == $arena_head && n == 4
continue
tbreak buddy_insert_free_block
continue
finish
p $arena_head->property
p buddy_nr_free
p buddy_free_area[2].nr_free
p buddy_free_area[3].nr_free
p buddy_free_area[4].nr_free
```

其中最后五条查询对应图 G13 的 16、16、0、0、16。这里的计数属于隔离测试区，各阶 `nr_free` 是页数而不是块数。
